The missing facts stay visible.

Teachers and community organizers often rewrite the same event details into an invitation, a schedule, a checklist and a budget. Flow Point prepares those documents together, then gives the organizer control over corrections and approval.

No account needed. The hand-authored sample uses no AI. Live Prepare and Update send your notes to __AI_PROCESSOR__ after your processing choice. The fictional judge brief is safe example data, not a real booking.

What the checks prove

Open Source cards beside facts in Details, Checklist and Budget. Compare the saved quote with the value; a quote found in a note is not proof of its meaning. Missing quotes or manual corrections need your confirmation. Saved notes & updates are available above the event details. Older packs have no invented source history.

Code checks structure, calendar dates, exact integer money arithmetic, missing details and whether approval matches the edited version. These checks cannot prove that every sentence matches the brief. Human review remains necessary. No invitations are sent and no bookings are made.

Why open-weight AI matters here

__AI_MODEL_LABEL__ interprets varied notes and proposes wording. Its open weights allow a future self-hosted implementation and model inspection; this release uses the configured provider’s hosted API and does not run offline. The server adapter and validation code are open source, so the generation boundary can be inspected and changed.

Evidence and limits

Source-review checks, real failures and limits

Dated live results and failures · Reproduction guide · Exact brief, update and expected values · Source and automated tests

The automated suite uses simulated provider responses. Live measurements are recorded separately with request IDs and checks. Manual writing time and human review effort have not been measured, so no percentage time saved is claimed. Provider outages, quota and model errors can still prevent completion. Browser checkpoints preserve completed replies; they cannot recover a provider reply that never reached this browser, and do not guarantee exactly-once requests.

Tools with specific jobs

The earlier walkthroughs and submission describe the Google Gemma implementation. The active provider and model are shown in the workspace; current generation may use Groq and GPT-OSS. Historical recordings are not proof of the active provider.
