# Flow Point demo recording guide

Target: 75 to 100 seconds. Record the real deployed site at `https://flowpoint.phoenixreborn.tech/workspace`. Use fictional data only. Do not call the hand-authored sample a live model run. Do not claim the video proves a measured time saving.

| Time | Screen | Say or show |
| --- | --- | --- |
| 0-8 s | Notes page, full writing area | “One rough event note usually becomes an invitation, schedule, checklist and budget.” |
| 8-22 s | Paste a prepared fictional brief, with one missing fact and one unknown price | “Flow Point asks Gemma for a first draft, and it keeps unconfirmed facts visible.” Show the Google-processing checkbox before sending. |
| 22-35 s | Generate, wait for the real response | Do not trim away an error or replace a failed call with sample output. If provider is unavailable, use a separate clearly labelled recorded run and say when it was captured. |
| 35-49 s | Details and review questions | Show the missing time question and confirm the budget still has a blank unknown price. |
| 49-63 s | Update pack with a confirmed start time | Show the update consent and the live Gemma result. The date, venue and prices must remain consistent. |
| 63-79 s | Invitation, proposed run of show and budget | Show the confirmed start time, later times labelled suggested, and the incomplete subtotal. |
| 79-95 s | Download draft PDF | Open the PDF. Show “DRAFT / Review required” and the unknown price. End with “It does the first pass. I make the final call.” |

Recording notes:

- At a phone viewport, ensure the notes and pack views remain readable; desktop capture is easier for the budget. Use one format consistently unless the transition is explained.
- Pause long enough to read each fact. A cursor sweeping quickly across tabs does not show the output.
- Mask any real personal data before capture. The fictional Repair Day example in `docs/verification.md` is safe to show.
- If a generated result has placeholders, say they need review. Do not mark the pack approved to make the video look complete.
- If adding narration, use the author's own voice. This script is a guide, not a fabricated user testimonial.
- Add a real video link in the DEV draft only after upload succeeds and playback is checked. The live app and screenshots already satisfy the challenge's demo-link requirement.
