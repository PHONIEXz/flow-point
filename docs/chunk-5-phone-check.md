# Quick real-phone check

Status: prepared, not performed by the agent. This checks editing/storage/download usability without AI calls, so it can proceed while provider quota is blocked. It is not a test of AI generation or a timed manual-writing comparison. Save any current unnamed work before starting a separate sample.

1. Open the live workspace on your real phone. Open the sample and save it as a named pack, such as Phone check.
2. Visit all five pack tabs. Check readable text, usable buttons, no overlap and no sideways page scrolling. Switch light/dark once. Try both letter styles. In Letter details, set a letter date, apply the layout and check that it is separate from the event date.
3. In the sample Budget, keep both quantities at 50. Enter NGN 300 for refreshments and NGN 100 for programmes. Expect NGN 20,000 total. Set a NGN 30,000 spending limit and expect NGN 10,000 remaining.
4. Download and open the invitation PDF and full-pack PDF on the phone. Check readable paragraphs, page breaks and draft status. Download the invitation a second time and check the files have different unique names beginning with the event title.
5. Refresh and reopen the named pack. Check that the prices, letter style/date and edited wording remain. Do not clear browser storage during the check.

If you time it, start when you open the sample and stop after the PDF opens and saved values are checked. Record actual elapsed time and any interruption; otherwise leave time unmeasured. This is a small owner usability check, not a productivity study. AI Prepare/Update, Compare and Restore remain pending live/physical-device checks.

Reply: phone model/browser; readable yes/no; PDFs open yes/no; saved values retained yes/no; elapsed time if measured; any problem and the step where it happened. No screenshots are required unless helpful for a specific problem.
